Amazon Product Data Analysis

About the Project

I worked on this project to understand how data analysis can be used to explore product information from Amazon.

The dataset contains details such as product names, prices, discounts, ratings, and other product-related information. I used Python to clean the data, explore different patterns, and understand how products compare based on their pricing and customer ratings.

What I Worked On

Loaded and explored the Amazon product dataset.

Checked for missing values and duplicate records.

Cleaned and prepared the data for analysis.

Analyzed product prices and discount percentages.

Explored customer ratings and rating counts.

Identified highly rated products.

Compared products based on their prices and ratings.

Created visualizations to understand the findings.

Dataset

The project uses an Amazon product dataset containing 1,000+ product records.

The dataset includes information such as:

Product names and categories

Actual and discounted prices

Discount percentages

Product ratings

Rating counts

Analysis Performed

1. Data Cleaning

Checked missing values.

Removed duplicate records where applicable.

Converted price and rating columns into suitable data types.

Prepared the dataset for further analysis.

2. Exploratory Data Analysis

Explored product price distributions.

Compared actual prices with discounted prices.

Analyzed discount percentages.

Studied customer ratings and rating counts.

Examined relationships between numerical variables.

3. Data Visualization

Created charts using Matplotlib and Seaborn to make the analysis easier to understand.

Some of the areas explored include:

Product price distribution

Discount percentage comparison

Customer rating distribution

Highly rated products

Relationship between prices, discounts, and ratings

How to Run

Clone this repository:

git clone https://github.com/SionRani/amazon-product-data-analysis.git

Open the project folder.

Install the required libraries:

pip install pandas numpy matplotlib seaborn jupyter

Start Jupyter Notebook:

jupyter notebook

Open the notebook and run the cells.
